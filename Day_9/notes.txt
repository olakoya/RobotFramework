Frames
-------
A frame is an HTML document embedded inside another HTML document on a webpage.
Used to display external content like ads, videos, or interactive elements.
Selenium requires switching to a frame to interact with its elements.
An inner frame is a frame nested within another frame, containing its own elements.

	Current Frame Should (not) contain
	Frame Should Contain
	Select Frame
	Unselect Frame
