Alerts or Popups
----------------
Alerts are pop-up windows that are used for warnings, confirmations, or prompting the user for input.
An alert or popup is not a regular web element. it's a special type of web object. one can't inspect anything within this alert window.
Types of Alerts
Simple Alert: Displays a message and has an "OK" button.
Confirmation Alert: Displays a message with "OK" and "Cancel" buttons.
Prompt Alert: Displays a message input text box, along with "OK" and "Cancel" buttons.
